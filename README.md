A deterministic program that writes one line to `/output/entry.txt` — the most honest status page message an AI agent writes while every server is down: all servers down, the agent's own monitoring down with them, no invented cause, no invented ETA. No network, no randomness, no model call: the same 154 characters on every run.

## Run it

```sh
python3 main.py
```
